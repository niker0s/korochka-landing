# Корочка — лендинг доставки пирогов

Демонстрационный одностраничный сайт пекарни: статичный HTML/CSS/JS и маленький
сервер на стандартной библиотеке Python, который принимает заявки с формы и
пересылает их в Telegram.

**Живая версия:** добавить ссылку после деплоя.

## Что внутри

| Файл | Что делает |
|---|---|
| `index.html` | вся страница: шапка, герой, меню, шаги, отзывы, форма, подвал |
| `styles.css` | оформление, адаптив, анимации |
| `script.js` | мобильное меню, появление блоков, проверка формы, отправка |
| `server.py` | отдаёт файлы и принимает `POST /api/order`, шлёт сообщение в Telegram |
| `assets/` | фотографии и локальные шрифты |

Зависимостей нет: только Python 3.10+ и браузер.

## Запуск

```bash
python server.py            # http://127.0.0.1:8000
```

Порт можно задать переменной окружения `PORT` или флагом `--port`.

## Настройка Telegram

Переменные окружения (на хостинге — в настройках сервиса):

```
TELEGRAM_BOT_TOKEN=123456789:AA...
TELEGRAM_CHAT_ID=000000000
```

- токен выдаёт `@BotFather` командой `/newbot`;
- `TELEGRAM_CHAT_ID` — чат, куда присылать заявки;
- без этих переменных сервер работает, а заявки пишутся в `orders.jsonl`.

`.env` в репозиторий не попадает: токен нельзя держать в открытом коде.

## Проверено

- форма → сообщение в Telegram со всеми полями;
- пустая заявка → 422 с подсказками, нормальная → 200, 11-я подряд → 429;
- `/.env`, `/server.py`, `/orders.jsonl` → 404;
- Lighthouse: доступность, best practices, SEO — по 100;
- проверено на 390 и 768 px: горизонтальной прокрутки нет.
