Замечания:

- CC BY — нужна подпись автора (достаточно строки в подвале).
- CC BY-SA — производные работы распространяются под той же лицензией;
  для коммерческого лендинга неудобно, лучше заменить.
- GFDL 1.2 — требует приложить полный текст лицензии; для сайта не подходит,
  только для демонстрации. Заменить в первую очередь.
